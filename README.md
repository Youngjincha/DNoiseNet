This repository contains noise data used to train and test DNoiseNet (Chat et al 2023), a deep learning–based feedback active noise control system designed to reduce unwanted noise across a range of environments. It also includes the DNoiseNet implementation and the code used to compare its performance with that of other networks.

If you use the data or code in your research, whether in its original or modified form, please cite the following article.

Cha, Y. J., Mostafavi, A., & Benipal, S. S. (2023). DNoiseNet: Deep learning-based feedback active noise control in various noisy environments. Engineering Applications of Artificial Intelligence, 121, 105971.
